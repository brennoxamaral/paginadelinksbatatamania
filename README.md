# 🥔 Batata Mania - Página de Links (Bio Link)

Página oficial de links estilo *Bento / Linktree* da **Batata Mania** (@batatamania.cassi), desenvolvida com foco em alta conversão, performance, responsividade e design exclusivo.

---

## 🚀 Funcionalidades

- **Identidade Visual Personalizada:** Paleta de cores exclusiva com padrão de fundo orgânico ilustrado em SVG.
- **CTAs de Destaque:**
  - 📋 **Ver Cardápio:** Link direto para o sistema de pedidos Brendi.
  - 💬 **Pedir pelo WhatsApp:** Mensagem pré-formatada direta para o atendimento.
- **Redes Sociais:** Acesso rápido ao Instagram e TikTok.
- **Vitrine de Produtos Recomendados:**
  - Kit 365 Versículos (Site oficial)
  - Potes Térmicos FIBRAFORM (Shopee)
  - Panela Elétrica (Shopee)
  - Frigideira Dupla (Shopee)
- **Otimizações Modernas:**
  - `fetchpriority="high"` e `decoding="async"` para carregamento rápido.
  - Fallbacks dinâmicos em SVG caso imagens externas falhem.
  - Totalmente responsivo para smartphones, tablets e desktops.
  - Acessibilidade e suporte a `prefers-reduced-motion`.

## 🌐 Como Publicar no GitHub Pages

1. Acesse o repositório no GitHub: [brennoxamaral/paginadelinksbatatamania](https://github.com/brennoxamaral/paginadelinksbatatamania).
2. Vá em **Settings** > **Pages** (no menu lateral esquerdo).
3. Em **Build and deployment** > **Source**, selecione **Deploy from a branch**.
4. Em **Branch**, selecione a branch `main` e a pasta `/(root)`, depois clique em **Save**.
5. Em instantes, seu site estará no ar no endereço:  
   `https://brennoxamaral.github.io/paginadelinksbatatamania/`
